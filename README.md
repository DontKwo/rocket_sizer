# RocketSizer

RocketSizer is a launch vehicle conceptual sizing, heritage cataloging, and trade study platform built with Tauri v2, a Rust numerical core, and a React/TypeScript interface.

## Capabilities

- **Hybrid Sizing**: Combinatorial multi-stage search paired with a real-time manual sandbox.
- **Flight Milestones**: Models fairing jettison sub-phasing, Max-Q throttle reduction, and G-limit throttling.
- **Reusability**: Dedicated profiles for expendable, downrange barge landing (ASDS), return-to-launch-site (RTLS), and parachute recovery.
- **Structural Physics**: Hoop stress, compressive buckling, and material presets (Al-Li, CFRP, Stainless Steel).
- **Engine Packaging**: 2D concentric circle-packing solver with TVC gimbal envelopes and no-touch clearances.
- **Heritage Catalogs**: Comprehensive launch vehicle and rocket engine datasets with complete citation provenance.
- **Parametric Costing**: Life-cycle cost estimation (DDT&E, TFU, recurring, refurbishment) with multi-objective optimization.
